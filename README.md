# Netflix Clone

## About the Project
This is a Netflix-inspired website created as a frontend development project. It recreates some of the visual elements of Netflix using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Netflix-inspired user interface
- Movie and show images
- Styled profile and content pages

## Live Demo
https://netflix-clone-hazel-nu.vercel.app

## What I Learned
Through this project, I practised building web pages, styling layouts with CSS, and organising frontend project files.
